# Tool mods survey: special tools for the gathering trees (2026-10-10)

Follows the decision in `docs/answered/gear.md` (REQUEST 2026-10-10, Skyy): "(check for mods that add more tool options too, so we can do like we did with armory, and give more loot options for the gathering trees too. (special pickaxes you cant craft, you can only find and get from quests. (with things like auto smelt, and vein mine.)" -> research Hytale mods adding tools / special tools (vein mine, auto smelt, tree feller, hammers / excavators) to list as pack mods (Armory pattern: runtime ids only, credit, author permission) plus our own UT / quest-only special tools for the gathering trees.

Related locks this must fit: tool levels + Mining / Foraging / Farming gates (`docs/answered/gear.md` 2026-10-02, spec `research/Tool-Levels-Spec.md`); crafted tools roll rarity + tool modifiers and reforge (`docs/answered/gear.md` 2026-10-10, SkyyGear 0.2.17); tool speed tiers never on tools (2026-10-06); Tree Feller already exists as a SkyyTrees perk (`docs/answered/gear.md` NOTE 2026-10-05, `docs/answered/skills.md` 2026-09-25); UT sources are mob drops, chests, bosses and quests, never crafted or sold (`docs/answered/gear.md` 2026-10-08); wardrobe loadouts carry tools in the hotbar and later gathering abilities (2026-10-10). Pack rules: `PACK.md` (runtime ids only, never copy or bundle files, credit, ask All Rights Reserved authors). Format and judging follow `research/Mods-Folder-Survey.md`.

Method: every jar / zip in `C:\Users\SkyLo\AppData\Roaming\Hytale\UserData\Mods` read in memory with python zipfile (nothing written, extracted or moved there; no scratch folder needed): manifests, item JSON, class strings. Web: CurseForge pages fetched 2026-10-10 (Modtale and GitHub searches returned nothing Hytale-specific for tools). CurseForge "Early Access" in the version field only means the file was uploaded before the 0.5 / 0.6 tabs existed; I list the Hytale cap from the manifest where I have the file.

## 1. Short answer

1. No installed or web mod gives us a ready "found-only special pickaxe" - every tool mod ships CRAFTABLE items. Quest-only is something WE add (loot tables, quest rewards, hidden recipes). Removing a mod's recipes needs an item-file override, which PACK.md forbids, so a pack mod's pickaxes would stay craftable unless we can hide recipes at runtime (needs a probe, Question 4).
2. Vein mine, auto smelt, fortune, silk touch, tool auto-repair: ALL CODE (a break-block listener in a plugin). The items themselves are plain pickaxe copies; the plugin reads the held item id (PJ-HyperPickaxes) or a key / permission (VeinMining). Nothing in item JSON does it.
3. 3x3 / 5x5 breaking is possible with the VANILLA engine and no code: Marsi Dungeon's "Blaze Reap" pickaxe does a charged hit that runs a Selector with `Block_Break_Adventure` over a 3x3 window (see section 3). Hammers / excavators from DanielBelmes do the same through a small interactions library.
4. Magnet is code (Item Magnet pulls dropped item entities toward the player).
5. Best fit by licence: AffixPlus (Public Domain), VeinMining (MIT), Multitools (MIT), Mining Hammers and Excavators (MIT), Lucky Mining (MIT). Most useful but All Rights Reserved: PJ-HyperPickaxes (PedriJoe), Item Magnet (Jaredlll08), Endgame&QoL (Lewaii). Recommendation: build our own special tools (Section 5) and use the MIT / Public Domain mods only as references or optional pack mods; ask PedriJoe once for the HyperPickaxes ideas (the same author as Forgotten Creatures on the B list in `research/Mods-Folder-Survey.md`).

## 4. Gaps and traps found

- Every tool mod's metals use plain vanilla material names, so SkyyGear's "Level by material" rows and the gate-skill matching by item id words (Pickaxe / Hatchet / Shovel / Hoe / Sickle) would treat them like normal tools - check on a probe before listing any.
- PJ-HyperPickaxes and Endgame both claim `Items.Tools` items with rarity names (Quality Uncommon, Legendary); our rarity ladder (Normal / Common / Uncommon / Rare / Epic / Legendary / Mythic / Untiered) is set by SkyyGear at runtime from the item id, so their `Quality` field is ignored in the tooltip (confirm with Quirk's tooltip work).
- Durability is off by default on the server (`docs/answered/gear.md` 2026-09-30): durability-cost downsides on special tools (VeinMining style) are meaningless; use other downsides (below).
- Only three licences let us touch the code: MIT (VeinMining, Multitools, Hammers and Excavators, Lucky Mining) and Public Domain (AffixPlus). Everything else: ideas only, no copying.

## 5. Our own special tools (quest / loot only)

All are UT-style (see `docs/answered/gear.md` 2026-10-08): never crafted, never sold; sources are mob drops, loot chests, bosses and quest rewards. Level = the gating skill, found at a level inside the zone band, and they ride the 0.2.17 tool rarity / modifier / reforge system (rarity = Untiered orange; modifiers still reroll). No weapon speed tiers (2026-10-06). Each has one strong ability and a trade-off, like our Untiered gear; the downside is deliberately NOT durability (off by default). ## 6. Questions for Skyy

1. Build all special tools ourselves (recommended) or also list VeinMining (MIT) as a pack mod for the vein effect? Default: ourselves, no VeinMining (the pack goal is "every mod is ours" and VeinMining works with every pickaxe).
2. How do these tools rank? Default: Untiered orange tools sit inside the zone band like UT gear, level equals the dropped zone band, and ability strength scales with the tool level (e.g. vein size, 3x3 stays 3x3).
3. Should the vein / smelt / 3x3 effects work with any pickaxe if you equip a Mining skill-tree perk instead of an item? Default: no, items only (perks stay the old Tree Feller exception already built).
4. Quest-only: OK that a hidden recipe (we override our own items only) is how crafting is blocked, and that we never list a mod whose pickaxes are craftable? Default: yes; do not list PJ-HyperPickaxes, Endgame or Multitools as pack mods.
5. Multitool (pickaxe + hatchet) as a quest reward: which skill gates it? Default: needs Mining AND Foraging at the item level (the higher of the two as the display level).
6. Magnet: tool ability (#4, #10) and also an Accessory Table item that works for all pickup? Default: tool ability only for now.
7. Downsides for tools - OK with "slower mining / half XP / no ground pile" style (no durability downsides while durability is off)? Default: yes.
8. Do you want me to message PedriJoe (HyperPickaxes + Forgotten Creatures) now? Default: yes, one message, asks for permission to list both as stopgaps and for the item-id rule.
9. Gathering-tree abilities (wardrobe 2026-10-10 says "simple, same across classes later"): do special tools carry the ability or does the loadout? Default: the tool carries the ability (tool = marker), loadouts just choose which tool is in the hotbar.
