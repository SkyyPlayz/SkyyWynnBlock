# Class emblems - icon concepts (7 classes, 64 x 64 + 128 x 128)

Cloud draft, 2026-10-06. Paper design; nothing built. Original pixel art, generated by code
(`research/cloud/class-art/make_emblems.py`, Python + Pillow). No copied art, no game files.
Inputs read: `CLOUD-RESUME.md` ("Class emblem icons"), `research/classes/README.md` + each class file (roles, weapons),
`research/Classes-Berserker-Priest-Spec.md` 2.1 + `SkyyProfiles/build_skyyprofiles_0.1.2.py` (the class colours `ClassDefs.COLORS`),
`research/Vanilla-UI-Style-Guide.md` section 5 (UI colours), `docs/answered/gear.md` (ART RULES 2026-10-06).

**Start here:** `research/cloud/class-art/class-sheet.png`.

## 2. The crest (same for every class)

| Layer | Colour | Why |
|---|---|---|
| Outer trim + inner line + top gem setting | gold `#c9a24a` ramp | echoes the vanilla window's gold ornaments (UNVERIFIED exact colour) |
| Rim | slate `#34465a` ramp, rivets (4 at 64, 8 at 128) | the dark blue-grey of vanilla panels |
| Field | the class colour, darkened, split "per pale" (left lit, right shaded) with a faint lozenge pattern | class colour = `ClassDefs.COLORS`, so cards, names and icons match |
| Top gem | class colour | reads the class even at 32 px |
| Symbol | real materials (steel, wood, black leather, gold) | the weapon reads first, the colour second |
