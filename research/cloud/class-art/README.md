# Class emblems - icon concepts (7 classes, 64 x 64 + 128 x 128)

Cloud draft, 2026-10-06. Paper design; nothing built. Original pixel art, generated by code
(`research/cloud/class-art/make_emblems.py`, Python + Pillow). No copied art, no game files.
Inputs read: `CLOUD-RESUME.md` ("Class emblem icons"), `research/classes/README.md` + each class file (roles, weapons),
`research/Classes-Berserker-Priest-Spec.md` 2.1 + `SkyyProfiles/build_skyyprofiles_0.1.2.py` (the class colours `ClassDefs.COLORS`),
`research/Vanilla-UI-Style-Guide.md` section 5 (UI colours), `docs/answered/gear.md` (ART RULES 2026-10-06).

**Start here:** `research/cloud/class-art/class-sheet.png`.

## 1. Files

| File | What |
|---|---|
| `class-sheet.png` | Row 1: each 128 icon at 2x. Row 2: 128 at 1x, 64 at 2x, 64 at 1x, 64 "locked". Row 3: a mock Profiles class card |
| `icons/class-<name>-128.png` | 128 x 128, transparent (Profiles class cards) |
| `icons/class-<name>-64.png` | 64 x 64, transparent (Stats page, small lists) - drawn natively at 64, not shrunk |
| `icons/class-<name>-64-locked.png` | grey "coming later" version (Assassin and Monk are not selectable yet) |
| `make_emblems.py` | The generator. Deterministic. Run `python3 research/cloud/class-art/make_emblems.py` |

Folder size about 0.35 MB.

## 2. The crest (same for every class)

| Layer | Colour | Why |
|---|---|---|
| Outer trim + inner line + top gem setting | gold `#c9a24a` ramp | echoes the vanilla window's gold ornaments (UNVERIFIED exact colour) |
| Rim | slate `#34465a` ramp, rivets (4 at 64, 8 at 128) | the dark blue-grey of vanilla panels |
| Field | the class colour, darkened, split "per pale" (left lit, right shaded) with a faint lozenge pattern | class colour = `ClassDefs.COLORS`, so cards, names and icons match |
| Top gem | class colour | reads the class even at 32 px |
| Symbol | real materials (steel, wood, black leather, gold) | the weapon reads first, the colour second |

## 3. One line per class

| Class | Colour | Symbol |
|---|---|---|
| Warrior | `#e0b060` | sword crossed over a spear (Swords, Spears) |
| Berserker | `#d9443f` | double-bit battleaxe crossed with a flanged mace (Axes, Maces) |
| Archer | `#8fd67a` | recurve shortbow with a nocked red-fletched arrow (Shortbows) |
| Assassin | `#b58cff` | dagger crossed with a ring-pommel kunai (Daggers, Kunai) |
| Mage | `#7fb0e0` | staff with a violet orb in a gold claw + sparkles, spellbook at its foot (Staffs, Spellbooks) |
| Priest | `#f2e6a0` | the Soul Orb (gold cage, glowing soul) under a halo, with a wand (Wands, Soul Orb) |
| Monk | `#ff7a5c` **(proposal)** | bo staff crossed with three-blade claws on a black leather wrap, wind swirls for speed (Bo staff, Fist weapons) |

- Monk has no class colour yet. Proposal: `#ff7a5c`, the old Shaman slot colour (the Monk replaces the Shaman slot).
- Claws follow Skyy's weapon lock (long straight Wolverine-style blades, black leather).
- Colours are the live `ClassDefs.COLORS` values (SkyyProfiles 0.1.2 build script) - if those change, edit `CLASSES` in the script.
