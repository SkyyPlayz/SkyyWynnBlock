# Light armor - concept sheets (Copper ... Onyxium)

Cloud draft, 2026-10-06. Original pixel art, generated by code (`research/cloud/light-armor/make_sheets.py`, Python + Pillow) - no copied
art, no game files. Concept only; nothing built. Inputs read: `docs/answered/gear.md` (LOCKED 2026-10-05 black-leather reference, "light
armor keeps the leather look and adds metal on it", "echo the normal metal armors style"; LOCKED 2026-10-06 "copper black leather."),
`CLOUD-RESUME.md` (the LIGHT ARMOR CONCEPT SHEETS item), `research/cloud/Foraging-Armor-Design.md` section 7 (the echo table used there).

**Start here:** `research/cloud/light-armor/light-armor-sheet.png` (all tiers, front row + back row).

## 2. Decisions followed

1. Tier 1 (Leather, Lv 1-13) = **vanilla leather armor, no new design** (Skyy 2026-10-06 "copper black leather."). It is only a greyed
   label on the sheet. The black-leather design starts at **Copper**.
2. Every tier is the **same black-leather base** from Skyy's reference (described in words; the picture stays local): diamond-quilted
   scale chest, raised stand-up collar, 3 layered rounded shoulder caps, segmented upper arm / elbow / forearm guards, finger-less hand
   guards, brown diagonal chest strap, wide double waist belt with buckles, belt pouch on the left hip, long rectangular leather tassels
   (front, sides, back), small leaf-shaped accent pieces.
3. Each tier **adds its metal** (like the wands: wood handle + metal tip). Copper = plain trims; Iron and up also **echo that metal's
   vanilla armor** in shape, not only colour.
4. Accents **grow a little each tier**, but leather (black + brown) stays the majority. The script prints the metal share of the
   front view:

| Tier | Metal pixels / armor pixels (front) |
|---|---|
| Copper | 13.6% |
| Iron | 19.7% |
| Thorium | 27.2% |
| Cobalt | 26.9% |
| Adamantite | 30.9% |
| Mithril | 30.7% |
| Onyxium | 34.5% |

5. The same chest piece on the strap is the tier's "signature" (a ring buckle on Copper growing into a gem on Onyxium), so each
   tier reads at a glance even from the front icon.

Shared base palette: black leather `#0a090c` / `#1c191f` / `#2b2730` / `#3f3946` / `#58515f` (outline -> highlight); inner / far
leather `#121014` - `#2e2a33`; brown strap `#1c1009` / `#3e2516` / `#5c3a22` / `#7b5032` / `#9a6a44`; mannequin greys `#4a453f` - `#c6bfb0`.
Every part has a 1-px dark outline and a 4-step ramp lit from the top-left.

## 4. How to regenerate

```
python3 research/cloud/light-armor/make_sheets.py
```

Writes the 15 PNGs next to the script and prints the metal-share table. Same code -> same bytes (checked by running twice). To tweak a
tier: palettes are in `TIERS` at the top; the accent switches per tier are in `cfg_for()`; the figure is `draw_figure()` (parts painted
on a 64 x 84 grid; set images are scaled x5, chest close-ups x8, NEAREST).
