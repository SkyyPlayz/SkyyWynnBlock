# Loot box design - "better looking" unidentified drops

Cloud draft, 2026-10-06. Skyy: unidentified drops should be **Wynncraft-style rarity loot boxes** ("better looking"): a box colour per SkyyGear rarity, names like **"Unidentified Sword"**, a level **RANGE** (Skyy's pick, answering question 5 of `research/Loot-Unid-Spec.md`), tooltip mockups, identify messages and art direction for the generated art.
Builds on `research/Loot-Unid-Spec.md` (mystery items: 18 ids, grey "shadow" icons with a "?", non-stacking, the real item sealed in the stack, identify swaps in place; the drop glow follows the item's *asset* quality; frame and name colour follow the stack quality) and the art kit `tools/skyyart.py`.
Rarity colours read from `SkyyGear/build_skyygear_0.2.py` (RARITIES). Engine facts (icons per item id, per-stack display name, drop glow by asset quality) are quoted from the Loot spec's VERIFIED notes; anything else is UNVERIFIED.

## 0. The design in one picture

```
 [ a small voxel crate in the rarity's colour, a banded lid, a gold "?" lock ]
   + a white badge of the TYPE in the lower-right corner (sword, bow, chestplate ...)
 Name:      Unidentified Sword          (name coloured like the rarity)
 Level:     Lv 41-45                    (a RANGE, 5 wide)
 Rarity:    Legendary                   (word + the box colour)
 On the ground: the same crate model in the rarity colour, glowing in the rarity's drop glow
```
Skyy's three asks are covered: colour per rarity (box + glow + frame + name), "Unidentified <Type>" names, a level range.

## 2. How many item ids (the decision)

The Loot spec chose **18 ids** (one per type) and noted that per-rarity ids "break one mystery item per type, 108 ids: not done". With the box look the trade-off flips:

| Option | Ids | Icon shows | Glow on the ground | Cost | Verdict |
|---|---|---|---|---|---|
| **A. one id per type (current spec)** | 18 | a grey "?" shadow, frame colour by quality | one white glow for all | smallest | no colour at a glance |
| B. one id per **rarity** | 7 | the rarity box, **no type** | per rarity (asset quality) | small | type only in the name |
| **C. one id per type x rarity (recommended)** | **126** (18 x 7) | the rarity box **plus a type badge** | per rarity | 126 JSON + 126 icons + 7 textures + 1 model + 126 lang lines, all generated | best look, everything at a glance |

**Recommendation: C**, generated by the build (no hand work): the item JSON, icons and lang lines come from one table. The ids stay "gear" for the other mods (`Weapon_` / `Armor_` prefix rules do **not** apply: the ids are `Skyy_Unid_<TypeKey>_<Rarity>`).
If 126 ids prove heavy in game (item list, AH category filters, bag rules), fall back to **B**: the type then goes in the per-stack display name ("Unidentified Sword") and in the tooltip only.
Existing stacks of the old 18-id mystery items (if the loot round shipped them first) are migrated by the swap rule (section 7); the AH and `/identify` read both.

## 3. The level RANGE (Skyy's pick)

Wynncraft shows a **level range** for unidentified items. Rule:
| Rule | Value |
|---|---|
| Width | **5 levels** (e.g. 41-45) for real level 6 and up; **3 levels** below that (Lv 1-3, 2-4, 3-5); a Lv 1 item shows 1-3 |
| Where the real level sits | **random inside the range** (offset 0-4 chosen once from the item's seed and stored in the sealed data), **not always the middle**, so guessing is a real guess |
| Bounds | the range is clamped to the material band and never below 1; it may not span an impossible gap (no range across two bands that have no item: widen to the next valid level) |
| Stable | the shown range never changes after the drop (stored with the item); identifying shows the **exact** level |
| Tooltip | `Lv 41-45 - Requires Swordsmanship 41 (you: 38)`: the requirement line uses the **low end** (the minimum you will need) and the line is red / green as for gear |
| AH | the AH shows the range; sorting and search use the **low end** |
| Server Setup | `unid.rangeWidth` (5), `unid.rangeSmall` (3), `unid.showExact` (off: the Loot spec's old default; on = exact level, no range) |
Why it is fair: the material bands overlap (Wood 1-13, Copper 10-18, Iron 15-23, ...), so a range does not name the material but narrows it, as the Loot spec said about guessing "4 times in 10".

## 4. Art direction (the generated art)

### 4.1 The box model (one shared model, 7 textures)
| Item | Direction |
|---|---|
| Shape | a **chunky voxel crate / treasure box** about 12 x 9 x 9 pixels, a **slightly domed lid**, a vertical band, a front lock with a "?" engraved; the same silhouette for every rarity so it reads as "a drop" and the rarity is colour + ornament |
| Style | Hytale-vanilla look: hand-painted, low-saturation wood with bright accent colours, soft bevels, no photographic noise; match the vanilla chest textures' palette for the wood |
| Ornament ladder | 0 plain, 1 metal corner caps, 2 studs + a gem on the lock, 3 horns / crown ridge on the lid + bigger gem and a faint **emissive** edge (Fabled / Mythic) |
| Mythic extra | a small **floating sparkle** particle (the glow effect already exists as `Drop_Epic`); optional slow lid pulse (no animation needed for v1) |
| Generation | the 7 textures are generated from the vanilla chest texture (recoloured wood + our drawn bands / ornaments) with `tools/skyyart.py`; **nothing vanilla is committed**; the same texture size and UV layout as the vanilla chest (`Furniture_*_Chest` model), so no new model is needed: `Weapon_Sword_Steel_Rusty`-style re-texture (VERIFIED pattern in the Loot spec section 1.2) |
| Palette (rarity ramps, 3 stops each: dark / base / light) | Normal `#8a7a63 / #c9b896 / #f1e6cf`; Unique `#8a6d1f / #d4af37 / #fff2a8`; Rare `#6f2a6f / #b04ab0 / #ff9bff`; Legendary `#1f5f78 / #3fb4d4 / #a8f4ff`; Fabled `#6e1b1b / #c43a3a / #ff9a9a`; Mythic `#4a2a6a / #9a56c8 / #e6b8ff`; Set `#1f5a2a / #4cae5a / #b8ffbf` (placeholders for Skyy to approve) |

### 4.2 The icon (64 x 64 inventory art)
| Layer | Direction |
|---|---|
| 1 Box | the crate seen from the front-three-quarter, filling about 80% of the icon, in the rarity ramp |
| 2 Lock / "?" | a gold lock plate with a **"?" glyph** (the existing `SA.glyph_q` pixel "?"), the colour of the band |
| 3 **Type badge** | a **16 x 16 white silhouette** of the type in the **lower-right corner** with a 1 px dark outline: sword blade, bow, crossbow, spear, axe, mace, dagger pair, kunai, staff, wand, book, helmet, chestplate, gauntlet, leggings; derived at build time from the vanilla item's icon alpha mask (downscaled with threshold), so no vanilla pixels survive, only a silhouette |
| 4 Rarity pip | a tiny gem or star in the **upper-left** corner on Rare and above (0-3 pips for the ornament level) |
| Premultiplied check | like the Loot spec build checks: every pixel keeps r, g, b <= alpha, the "?" and the badge present, no vanilla colours (hue check against the ramp), byte-identical on a re-run |

### 4.3 Slot frame and tooltip (already by rarity)
The stack quality still gives the inventory slot frame colour and the name colour per rarity (the Loot spec 1.5); the box icon adds to it. The slot background tint should match the ramp base so the box does not clash.

## 6. Identify: messages, sound and effects

| Moment | Text / effect |
|---|---|
| Click Identify (page) | the page shows the **box art large** on the left, the range and cost; on the right "Identify - 490 coins"; the clicked button disables |
| Result popup (chat + page) | `Identified! It was a Mithril Sword - Lv 43, Rare.` in the rarity colour; the **range is replaced by the exact level**; the modifiers listed by the gear tooltip |
| Rarity flavour (1 line, random of 3 per rarity) | Normal: "A decent find." / Unique: "Somebody lost a nice one." / Rare: "The Void hiccuped in your favour." / Legendary: "Pebble would be impressed. Pebble is a rock." / Fabled: "Now that is a drop." / Mythic: "...that is not supposed to exist." / Set: "A piece of something bigger." |
| Sound | the vanilla chest-open sound, then a short rising chime whose **pitch rises with rarity** (7 steps), Fabled and Mythic add a low rumble |
| Particles | a puff of confetti in the rarity colour (low count: 12 particles Normal to 40 Mythic) at the player's position; Mythic adds a light beam for 1 s |
| Failure (not enough coins) | `You need 490 coins to identify this.` (the existing coins-first rule, no refund needed) |
| Several boxes | `Identify all` (existing) prints a summary: `Identified 5: 2 Normal, 2 Unique, 1 Rare (best: a Rare Iron Chestplate).` |
| Chat colour and AH | the AH list shows the box icon and the range; sorting by low end |

## 7. Migration and compatibility
| Topic | Handling |
|---|---|
| **Old 18-id mystery items** (Loot spec A) | stay valid; on first view the scan swaps them to the matching `Skyy_Unid_<Type>_<Rarity>` id in the same slot (same swap as identify, no data loss); a `unid.legacyConvert` row (on) |
| Old pre-loot "Unidentified Iron Sword" items | untouched (real items) |
| Auction House | one category per type as in the Loot spec; the box icon appears in listings |
| Bags | Magic Bags never pick boxes up (as the Loot spec says): id prefix `Skyy_Unid_` excluded |
| Trading | allowed (vault, trade, AH) |
| Lang | 126 names generated: `Unidentified <Type>` + rarity in the quality label |
| Mod compatibility | SkyyHud / AH / Vault read the box through the same id prefix; the SkyyGear mystery document and the sealed real id are unchanged |
