## 2. The shared look (every tier)

From Skyy's bark reference (picture stays local) and Foraging-Armor-Design section 7:

1. **Bark-plate chest** - three layered bark plates, each upper plate overlapping the one below with a jagged lower edge; vertical bark grain.
2. **Jagged bark tassels** at the hem (uneven sawtooth ends, darker side tassels behind the legs).
3. **Twisting vine / root trims** over the shoulder caps and along the collar; a twisted vine belt.
4. **Glowing sap / leaf-vein pattern** branching up the chest (a trunk + 6 branches). It brightens each tier and gets a soft halo from
   Hardwood up; from Hardwood up a smaller vein also runs up the back.
5. **Small leaves** on the collar, shoulders and belt (more leaves on Redwood / Goldenwood).
6. **Hands** = wrapped bark gauntlets (finger-less); **Head** = a bark crown (design section 7), a full hood only on Goldenwood.
7. Moss-grey cloth trousers under bark greaves and bark boots with a wrapped top.

## 4. How to regenerate

```
python3 research/cloud/foraging-armor/make_sheets.py
```

Palettes are in `TIERS` at the top; per-tier echo switches in `cfg_for()`; the figure is `draw_figure()` (64 x 84 grid + 8 rows on top for
crowns / thorns / hood; set images x5, NEAREST). Mask and painter helpers are copied from `research/cloud/light-armor/make_sheets.py` (not
imported, so that folder can change freely).
