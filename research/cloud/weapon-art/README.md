# Magic + new weapons - concept sheets (Copper ... Onyxium)

Cloud draft, 2026-10-06. Original pixel art, generated by code (`research/cloud/weapon-art/make_weapons.py`, Python + Pillow) - no
copied art, no game files. Concept only; nothing built. Inputs read: `CLOUD-RESUME.md` (the "Magic + new weapons concept sheet" item),
`research/SkyyArmory-Spec.md` 1.2 / 1.3 (wand art, style B) and 15 (staff ladder), `docs/answered/gear.md` + `docs/answered/classes.md`
(wand lock and the 2026-10-02 art proof note), `research/cloud/Spellbook-Ladder.md` 1, `research/cloud/Soul-Orb-Spec.md` 1,
`research/cloud/Kunai-Ladder.md` 7, `research/cloud/Monk-Kit-Spec.md` 1-2. Style, painter and metal palettes copied from
`research/cloud/light-armor/make_sheets.py` (that folder is unchanged).

**Start here:** `research/cloud/weapon-art/weapon-sheet.png` (rows = weapon type, columns = metal).

Total PNG size about 185 KB. Every icon is painted on a 48 x 48 grid (inventory-icon size), 1-px dark outline, 4-step shade ramp lit
from the top-left, scaled x4 with NEAREST. Long items lie on the diagonal (butt bottom-left, tip top-right), like vanilla-style icons.

Note: `research/cloud/Spellbook-Ladder.md` 1 and `research/cloud/Kunai-Ladder.md` 7 describe Thorium as "pale green-grey", Adamantite "deep red-bronze", Mithril
"silver-blue" and Onyxium "black with violet lines". This sheet uses the light-armor ramps instead (one palette for all SkyWynn metal
art); both are guesses until the vanilla colours are checked.

## 4. How to regenerate

```
python3 research/cloud/weapon-art/make_weapons.py
```

One `draw_<type>(tier)` function per row; palettes at the top; `ROWS` sets the sheet order and the row notes.
