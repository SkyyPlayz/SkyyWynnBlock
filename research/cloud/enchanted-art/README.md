# Enchanted materials - icon concepts (37 items + 15 blocks, 64 x 64)

Cloud draft, 2026-10-06. Paper design; nothing built. Original pixel art, generated by code
(`research/cloud/enchanted-art/make_enchanted.py`, Python + Pillow). No copied art, no game files.
Inputs read: `CLOUD-RESUME.md` ("Enchanted material icons"), `research/cloud/Enchanted-Materials-Draft.md` (the mining, foraging
and farming tables), `docs/answered/bags.md` (LOCKED 2026-10-05: compressed materials like SkyBlock's Enchanted Iron / Cobblestone),
`docs/answered/gear.md` (ART RULES 2026-10-06: 64 x 64 icons, vanilla density), `research/cloud/accessory-art/` (painter style).

**Start here:** `research/cloud/enchanted-art/enchanted-sheet.png`.

## 3. The glint (SkyBlock style)

Every Enchanted icon = the base drawing + the same four touches, so players learn "shimmer = compressed":

| Touch | Value (placeholder) |
|---|---|
| Violet tint over the whole item | 7 % toward `#a858ff` |
| Shimmer band 1 | diagonal, 7.5 px half-width, 62 % toward `#eeceff`, stepped in 3 bands so it stays crisp pixel art |
| Shimmer band 2 | thin, 3 px, 45 %, 28 % of the icon behind band 1 |
| Halo | 1-px soft violet ring outside the outline (alpha 70) |
| Sparkles | 4 four-point stars at fixed spots (top-right, left, bottom-right, top) |

Blocks get the same glint, so an Enchanted Block reads as "the next step" by being a cube, not by a second effect.

## 4. How the glint could be done in game (UNVERIFIED)

| Option | How | Good | Risk |
|---|---|---|---|
| **A: baked** (what these PNGs are) | the glint is painted into each item's icon texture | works with plain item icons, nothing engine-side | no movement; the 3D dropped / held item model would need its own glinted texture too |
| B: animated overlay | the item (or its model) uses a moving shimmer layer, like the GIF | closest to SkyBlock's moving glint | needs the engine to support animated item textures or a shader / overlay on item icons - **UNVERIFIED**; may be client-side only |
| C: baked icon + glowing model | baked icon in inventories; the dropped / held model gets an emissive or particle effect | cheap, still "alive" in the world | particles on dropped items: **UNVERIFIED** |

Recommended default: **A now** (it always works), check B / C locally later.
