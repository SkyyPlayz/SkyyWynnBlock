copied art, no game files. Concept only; nothing built. Inputs read: `research/cloud/Gathering-Armor-Mining-Farming.md` (1.1 Mining tiers and
looks, 2.1 Farming tiers and looks, 6 look notes, questions), `CLOUD-RESUME.md` (the Mining + Farming armor concept sheets item),
`research/cloud/light-armor/` (the style to match and the metal ramps), `docs/answered/gear.md` (Mining / Farming gathering armor = "later
ideas", 2026-10-05; FARMING ARMOR = crop armor and the working-lamp rule, both LOCKED 2026-10-06), `docs/answered/bags.md` (Lantern
accessory light, 2026-10-03 / 04), `research/cloud/Gathering-Tiers-Draft.md` 3 (Farming Bench crop order).

## 3. Farming v2 - CROP armor (straw-hat farmer look, made from the crop)

Skyy LOCKED 2026-10-06 (`docs/answered/gear.md`): "start with wheat armor, and work up through the food tiers making food armor, like in
skyblock" - and about v1: "i love the design". So v2 **keeps the v1 farmer silhouette** (wide straw-hat shape, rolled sleeves + bare
forearms, apron with pocket and neck straps, belt + buckle, scarf, long coat on the top tiers, crossed apron ties on the back) and makes
each set **from its crop**, one set per vanilla Farming Bench step. Each set's shape echoes the metal tier at the same level (the way the
Foraging sheet's woods echo the metals): Wheat = the old T0 Straw Farmer, Carrot = Copper Farmer (apron), Cauliflower = Iron (gloves,
wider brim, sickle, wrapped boots), Pumpkin = Thorium (scarf, clasps), Chilli = Cobalt (blue cotton, trimmed apron + cuffs), Cotton =
Adamantite (long coat), Onion = Mithril / Onyxium (coat + emblem + flower on the hat). No metal on the clothes any more; only the sickle
blade stays iron (a tool).

Why these crops (proposal, Skyy picks): the more iconic / easier-to-read crop of each pair, and colours that echo the metal at that level -
carrot orange ~ Copper, cauliflower cream ~ Iron's pale, pumpkin (SkyBlock's own Pumpkin armor) at Thorium, chilli red with Cobalt's
blue cotton, cotton white for the Adamantite coat, red-onion purple ~ Mithril / Onyxium violet. Swaps that also work: Lettuce (leafy
green ruffles), **Corn** (husk-leaf apron, kernel-gold hat), Turnip (purple-white bulb), Aubergine (glossy purple), Tomato (red, vine),
Rice (pale paddy straw, a conical hat), Potato (earthy brown, sack cloth). The other crop of each pair could be a **variant dye** of the
same set later.

Level bands are the metal bands (Crude 1-13, Copper 10-18 ... Mithril / Onyxium 40-49); all placeholders for Server Setup rows.

## 4. How to regenerate

```
python3 research/cloud/gathering-armor-art/make_sheets.py
```

Tiers are the `MINING` / `CROPS` lists (and `CROP_LOOK` for each crop set's ramps); colours are the named ramps; the figures are
`draw_miner()` and `draw_crop_farmer()`. `python3 research/cloud/gathering-armor-art/make_sheets.py --v1` also rewrites
`farming-sheet-v1.png` from the kept v1 code (`FARMING` / `draw_farmer()`), byte-identical to the original. Helpers
are copied from `research/cloud/light-armor/make_sheets.py` (not imported).
