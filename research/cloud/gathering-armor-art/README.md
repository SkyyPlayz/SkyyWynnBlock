# Mining + Farming armor - concept sheets

Cloud draft, 2026-10-06. Original pixel art, generated by code (`research/cloud/gathering-armor-art/make_sheets.py`, Python + Pillow) - no
copied art, no game files. Concept only; nothing built. Inputs read: `research/cloud/Gathering-Armor-Mining-Farming.md` (1.1 Mining tiers and
looks, 2.1 Farming tiers and looks, 6 look notes, questions), `CLOUD-RESUME.md` (the Mining + Farming armor concept sheets item),
`research/cloud/light-armor/` (the style to match and the metal ramps), `docs/answered/gear.md` (Mining / Farming gathering armor = "later
ideas", 2026-10-05).

**Start here:** `research/cloud/gathering-armor-art/mining-sheet.png` and `research/cloud/gathering-armor-art/farming-sheet.png` (8 tiers each,
front row + back row, labels, swatches).

## 1. Files

| File | What |
|---|---|
| `research/cloud/gathering-armor-art/mining-sheet.png` | Mining set T0 Miner's Leather ... T7 Onyxium Miner, front + back |
| `research/cloud/gathering-armor-art/farming-sheet.png` | Farming set T0 Straw Farmer ... T7 Onyxium Farmer, front + back |
| `research/cloud/gathering-armor-art/make_sheets.py` | The generator (deterministic: two runs give the same bytes) |

Same style as Light armor: 64 x 84 grid (+ 8 rows on top for hats, crests and the lamp glow), x5 NEAREST, 1-px outline, 4-step ramp lit
top-left, the same neutral faceless mannequin. T0 is drawn on both sheets (it is a new starter design in the spec, not a vanilla armor) -
see "For the local session" item 1.

Each tier **keeps the previous tier's pieces and adds its own** (the spec: every tier is an upgrade of the lower piece).

## 2. Mining - "Miner's gear" (dark leather + metal plates + lamp helmet)

Base for every tier: black leather (the Light armor leather `#0a090c` ... `#58515f`), grey work shirt `#383c44` ... `#737a84`, leather vest
with two chest ore pouches, a stone-grey strap across the chest, wide brown tool belt (`#3e2516` ... `#9a6a44`) with a buckle and a hip
pouch, leather gloves, knee pads, heavy boots.

| T | Set | Lv | Metal (light / mid / dark) | Lamp glow | What this tier adds |
|---|---|---|---|---|---|
| 0 | Miner's Leather | 1-13 | none: stone grey `#8c8c90` `#707074` `#56565a` | - | leather cap with a grey band, no lamp, no metal |
| 1 | Copper Miner | 5-18 | `#e89558` `#c26a34` `#8a4220` | `#ffd27a` 45% | copper hard hat + lamp (leather housing), copper rivets on the vest, steel-toe caps, buckles, glove rims, knee pads |
| 2 | Iron Miner | 15-23 | `#bcc4cc` `#8e97a2` `#5c646e` | `#ffe49a` 55% | smaller iron cap with rivets, small lamp, riveted iron shoulder plates |
| 3 | Thorium Miner | 20-28 | `#8cc08e` `#5e9468` `#3f6b4a` | `#fff2b4` 75% | taller thorium helmet, bright lamp in a metal housing, 2-layer shoulders, sandstone-coloured wraps (`#b8a070`) on forearms and shins |
| 4 | Cobalt Miner | 25-38 | `#6f95e6` `#3f63c4` `#2a3f8a` | `#d8ecff` 80% | blue-steel helm, lens visor (goggles), shale-grey cloak (`#4b545c`, folds) seen at the sides and covering the back |
| 5 | Adamantite Miner | 35-43 | `#e0574f` `#b42c30` `#7a1a20` | `#fff6dc` 90% + rays | heavy plates over the vest, ridged helmet, knee spikes, bracer bands, strong lamp |
| 6 | Mithril Miner | 40-49 | `#b4ecee` `#7ec4cc` `#4e8c98` | `#e6ffff` 100% + rays | pale mithril crest on the helmet, glowing lamp lens, glowing ore gem on the chest, cloak trim |
| 7 | Onyxium Miner | 40-49 (50+ later) | `#a06cda` `#6b3fa0` `#3e2460` + gold | `#ff8af2` 100% (violet) | black-onyx cloak, onyx plates, gold helmet band + two gold horns, gold chest plate, violet lamp glow |

The lamp is a cosmetic glow (spec question 4 default "glow only"); the glow halo and the rays are drawn on the background so the brighter
tiers read from far away.

Base for every tier: straw hat (woven, `#a8862e` ... `#f6e08e`), shirt with rolled sleeves (bare forearms), brown trousers, brown boots.

## 4. How to regenerate

```
python3 research/cloud/gathering-armor-art/make_sheets.py
```

Tiers are the `MINING` / `FARMING` lists at the top; colours are the named ramps; the figures are `draw_miner()` and `draw_farmer()`. Helpers
are copied from `research/cloud/light-armor/make_sheets.py` (not imported).
