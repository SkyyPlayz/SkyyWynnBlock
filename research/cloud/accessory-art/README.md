## 2. How the icon shows the rarity

The in-game probe of 2026-09-30 (spec 1.2) showed rarity **frames do not render** on our items, so the icon itself carries the rarity.
Every line keeps the same object at all 4 rarities, and adds one **gem in a metal setting**:

| Rarity | Name colour | Gem (colour = name colour) | Setting metal | Extra |
|---|---|---|---|---|
| Normal | `#FFFFFF` | 2 x 2, white | plain iron (`#77808a`) | - |
| Unique | `#FFFF55` | 3 x 3, yellow | gold (`#d4a234`) | - |
| Rare | `#FF55FF` | 5-wide diamond, pink, own dark rim | rose gold (`#c87c72`) | 4 claws on the gem, one pink glint top-right |
| Legendary | `#55FFFF` | 7-wide diamond, aqua | platinum (`#a8b8c8`) | claws, a 1-px soft aqua halo round the whole icon, 3 sparkles |

- The metal that changes is every metal part of the icon (chains, rings, bands, clasps, caps), not only the bezel, so the whole icon
  shifts colour with the rarity even at 1x.
- The line's own colour (red heart, blue mana, green leaves ...) never changes, so the line reads first and the rarity second.
- Lantern also grows its **inner light** each rarity (small glow -> glass almost full), echoing Skyy's lock "higher rarities reach
  farther".

- All icons stay inside a 2-px margin so the Legendary halo never touches the edge.

## 4. Style

Same painter as the light-armor sheets: each part is a pixel set with a 1-px dark outline and a 4-step ramp lit from the top-left, then
scaled with NEAREST (chunky pixels). Ramps (outline, dark, mid, light, highlight) are at the top of `make_icons.py`. Original shapes only;
nothing traced from vanilla or other mods.

## For the local session (UNVERIFIED)

- **Real icon size / format in Hytale:** 32 x 32 PNG with alpha is a guess. The vanilla item icon size, whether icons are PNGs inside
  the asset pack (and the path pattern `Icons/ItemsGenerated/...` or similar), and whether a mod jar can ship its own icon PNG instead of
  borrowing a vanilla icon path (spec 5.6 `icon_of`) all need a look in `Assets.zip` (read only). If vanilla uses 64 x 64, scale these
  2x NEAREST or redraw at 64.
- Whether a semi-transparent halo (Legendary, alpha 120) renders well on the real slot background, and whether icons are drawn over a
  dark or light slot.
- The icon is only the 2D inventory picture; the item's 3D model (spec 5.6 `visual_of`) is a separate question and is not drawn here.
- Accessories using our own icons means shipping new PNGs in the SkyyAccessories jar (our own art, so the public-repo rule is fine).
