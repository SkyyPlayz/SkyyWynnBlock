# Gems (idea, LATER) - Skyy 2026-10-11

Skyy's words are in `docs/answered/gear.md` (2026-10-11 GEMS). Not designed yet; this file collects the idea for a later spec.

- **What:** gems forged into gear slots (like SkyBlock gemstones). Each gem has ONE effect that depends on the gear it sits in.
  Example: a Haste gem = faster swing on a tool, more movement speed on armor (better on gear that already gives movement speed).
- **No levels, no rarities:** a gem is a flat bonus, either a number (+10 Mining Fortune) or a percent (+3 % movement speed).
- **Slots:** most gear 1 slot; Legendary, UT and special gear 2-3 slots. Slots can be added and removed (cost TBD).
- **Weapon gems:** e.g. more skill XP, more mob loot. These two should ALSO be rollable reforge lines (they aren't yet; the stat
  catalog scrapped "Magic Find" as a name - "Trophy Hunter" is the loot idea there).

Open for the spec: gem list per gear type, where gems come from (mining drops? bosses?), cost to add / remove a slot, whether a gem
comes back when removed, stacking caps, and how it shows in the tooltip (slot icons on the Sky Window frame).
Related: `research/Requip-Smithing-Spec.md` (Anvil tab), `research/Tool-Levels-Spec.md` (tool Upgrade Points).
