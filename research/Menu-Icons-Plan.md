# Menu icons - our own icons in every menu (plan, 2026-10-15)

Skyy 2026-10-15 (on the SkyWynn Menu Teleport page): "lets do our own icons in every menu too." (docs/answered/ui.md)
Goal: every SkyWynn menu / page shows our own SkyWynn icons instead of borrowed vanilla item icons.

## Rules
- **Family look** = the approved menu tiles (`art/menu-icons/README.md`, Skyy 2026-10-10: "beautiful! i love it"): 64 x 64 RGBA, hard
  alpha, 1 px violet-black outline, light from the top left, ramp-snapped palettes, category tints (Travel gold / amber, Your stuff
  teal, Money green / gold, Social violet, Admin steel). Art rules: `.claude/skills/skywynn-art/SKILL.md`.
- **Keep the item itself** where the page shows a real item (Bazaar / AH listings, Sacks, a collection's own item, gear, accessories,
  wardrobe, fishing gear, merchants, Vault, trade stacks, pickup feed cards). Only decorative / category / button icons are replaced.
- Original art only, generated by `tools/art/make_*.py` into `art/<set>/` (committed); never a vanilla file or recolour in git.
- One icon item per picture, hidden from the creative library (pattern: SkyyMenu `ICON_ITEMS` + `icon_item_png`, sha-checked against
  the art manifest). Sets used by several mods (skills, classes): each mod ships its OWN copy under its own id, so no mod needs
  another mod to be installed to look right [default; the PNGs are tiny].
- Process (visuals go-ahead, ui.md line 93): draw -> the local session reviews the sheet (layout + 32 px readability) -> implement in
  a normal round (patch scripts, PROJECT-RULES 4) -> Skyy sees it in game and asks for changes.
- Mods being built today (Gear, Sacks, Accessories, Hud, Quests, Islands, Trees) wait until their rounds are pinned.
