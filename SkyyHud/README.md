# SkyyHud

HUD widgets + editor (move / scale / hide), minimap

## Where things are
- **Which version is live:** the SET in `tools/deploy_set.py` (also `HANDOFF.md` section 1). Never assume the newest file here is live.
- **Build scripts:** `build_skyyhud_<ver>.py` = Java inside Python, compiled by `tools/skyybuild.py` (no javac). Most are GENERATED by
  `tools/hud_<ver>_patch.py` from the version before - edit the patch, never the generated script (except the 4 Skyy hand-edited
  ones listed in `RESUME.md` "Never forget").
- **Tests:** `test_skyyhud_<ver>.py` = the harness for that version (run it after a build).
- **Jars:** `SkyyHud-<ver>.jar` are built locally and git-ignored; old ones are in `backups/archive/`.
- **Skyy's decisions for this mod:** `docs/answered/ui.md` (word for word, newest line wins). Specs: `research/` (find them with
  `grep -l "SkyyHud" research/*.md`). History: `grep -n "SkyyHud" docs/log/*.md`.

## Where new things go
- A new version: a new `tools/hud_<ver>_patch.py` -> generated `build_skyyhud_<ver>.py` + `test_skyyhud_<ver>.py` here.
- Skyy's answers / ideas: `docs/answered/ui.md` via `python tools/qa_append.py ui <file>` (never in this folder).
- Rules for agents building here: `tools/AGENT-BRIEF.md` + `PROJECT-RULES.md`. Map of the whole repo: `INDEX.md`.
