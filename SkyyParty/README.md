# SkyyParty

parties, TPA buttons

## Where things are
- **Which version is live:** the SET in `tools/deploy_set.py` (also `HANDOFF.md` section 1). Never assume the newest file here is live.
- **Build scripts:** `build_skyyparty_<ver>.py` = Java inside Python, compiled by `tools/skyybuild.py` (no javac). Most are GENERATED by
  `tools/party_<ver>_patch.py` from the version before - edit the patch, never the generated script (except the 4 Skyy hand-edited
  ones listed in `RESUME.md` "Never forget").
- **Tests:** `test_skyyparty_<ver>.py` = the harness for that version (run it after a build).
- **Jars:** `SkyyParty-<ver>.jar` are built locally and git-ignored; old ones are in `backups/archive/`.
- **Skyy's decisions for this mod:** `docs/answered/social.md` (word for word, newest line wins). Specs: `research/` (find them with
  `grep -l "SkyyParty" research/*.md`). History: `grep -n "SkyyParty" docs/log/*.md`.

## Where new things go
- A new version: a new `tools/party_<ver>_patch.py` -> generated `build_skyyparty_<ver>.py` + `test_skyyparty_<ver>.py` here.
- Skyy's answers / ideas: `docs/answered/social.md` via `python tools/qa_append.py social <file>` (never in this folder).
- Rules for agents building here: `tools/AGENT-BRIEF.md` + `PROJECT-RULES.md`. Map of the whole repo: `INDEX.md`.
