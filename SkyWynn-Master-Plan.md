# PART 1 — THE RESEARCH

## 1A. Everything Hypixel SkyBlock has (2026 state)

**Skills (13: 11 main + 2 cosmetic)**
- Combat, Farming, Mining, Foraging, Fishing, Enchanting, Alchemy, Taming,
  Carpentry, Runecrafting (cosmetic), Social (cosmetic), Dungeoneering, Hunting (2025+)
- Auto-level from doing the activity; each level gives coins, stats, passive perks
- Skill level gates content (e.g., quick craft needs Carpentry III)

**Minions** — the heart of passive progression
- Placeable automatons on your private island; generate resources while OFFLINE
- Tier I–XI/XII: higher tier = faster + bigger internal storage
- Upgrades: fuel, storage add-ons, auto-compactors, hoppers (auto-sell)
- Minion-generated items DO count toward collections (bazaar-bought items do NOT)
- Minion slots earned via crafting unique minions → caps island automation

**Collections** — the progression backbone
- Nearly every gatherable item has a collection track (Farming/Mining/Combat/Foraging/Fishing/Boss collections)
- Milestones unlock CRAFTING RECIPES, trades, perks
- Only self-gathered or minion-gathered items count (anti-economy-bypass)

**Economy**
- **Bazaar**: instant buy/sell + buy/sell orders (stock-market style) for commodities
- **Auction House**: player listings + BIN (buy-it-now) for unique items (weapons, armor, pets)
- Coins from NPC sells, skill levels, minion hoppers, flips
- **Sacks** (bulk material storage), **Personal Bank** (interest, upgrade tiers)

**Items & gear systems**
- Rarity tiers: Common→Uncommon→Rare→Epic→Legendary→Mythic→Divine (+ recombobulator to upgrade rarity)
- **Reforging**: RNG stat prefixes on weapons/armor via Reforge Anvil + reforge stones (better prefixes)
- **Enchanting**: enchantment table + anvil combining; enchanted books; ultimate enchants
- **Accessories/Talismans**: collected accessories go in Accessory Bag → grant Magical Power → Tuning points (spend on any stat) + each has passive perk. Bag reforged as one via power stones (Thaumaturgy)
- **Pets**: leveling companions with rarity, perks, pet items; one active
- Stats system: Health, Defense, Strength, Crit Chance/Damage, Intelligence, Speed, Ferocity, Pristine, etc.
- HOTM (Heart of the Mountain): mining-specific skill tree with tokens — SkyBlock's ONE real skill tree
- Powder system (Mithril/Gemstone/Glacite) fuels HOTM nodes

**Content islands / zones**
- Private Island (yours) + Garden (farming island)
- Hub, Barn, Desert, Gold/Deep Caverns → Dwarven Mines → Crystal Hollows (procedural), Glacite Tunnels
- Spider's Den, End, Crimson Isle (faction quests, Kuudra boss), Park, Jerry's Workshop (seasonal)
- The Rift (upside-down dimension, unique mechanics), Backwater Bayou (Hunting), new 2026 fishing islands (Desecrated Shrine, Lotus Atoll)
- **Dungeons** (Catacombs): 8 classes-lite (Archer/Mage/Berserk/Healer/Tank), floors F1–F7 + Master Mode, secrets, score, dungeon-only gear
- **Slayers**: spawn-a-boss quest chains (Zombie/Spider/Wolf/Enderman/Blaze/Vampire + new 2026 Guardian), slayer XP unlocks recipes
- **Kuudra**: faction raid boss w/ gear-tier progression
- Events: Mayor elections (rotating global buffs!), Fishing Festival, Spooky, Jerry, Harvest Feast, Chocolate Factory (idle egg minigame)

**QoL / meta**
- **Quick Craft / Supercraft**: craft from inventory+sacks without knowing recipe layout, bulk crafts (unlocked via Carpentry + collection recipes still gate WHAT you can craft)
- Recipe book with progression tracking, Fairy Souls (exploration collectibles → permanent stats)
- SkyBlock Levels (account-wide progress number), Bestiary (kill collections → stats)
- Wardrobe, Ender Chest, Storage backpacks
- Co-op islands (shared profiles), profiles system (multiple saves)

## 1B. Everything Wynncraft has (2.1+ state)

**Classes & combat**
- 5 classes: Warrior, Archer, Mage, Assassin, Shaman (each with unique weapon type)
- 3 **Archetypes** per class (15 total) — themed sub-builds
- **Ability Tree**: 70+ nodes per class, top-down unlock paths, 45 Ability Points max (level-gated) — THE build system
- Spell casting via click combos (L-R-L etc.) — weapon-based spellcasting, mana (intelligence) management
- 5 **Skill Points** stats: Strength, Dexterity, Intelligence, Defence, Agility — gear has SP requirements
- 5 elements (Earth/Thunder/Water/Fire/Air) woven through damage, defense, gear

**Gear & itemization**
- Loot: massive fixed-item database with RNG **Identifications** (rolled stat % ranges) — re-rollable at Item Identifier NPC for emeralds
- Rarity: Normal/Unique/Rare/Legendary/Fabled/Mythic + Set items
- **Powders** (elemental, T1–T6): socket into weapon/armor slots, convert damage/add effects
- Level + skill-point requirements on all gear

**Professions (12)**
- Gathering (4): Mining, Woodcutting, Farming, Fishing — resource nodes in the open world w/ tiered tools
- Crafting (8): **Weaponsmithing, Armouring, Tailoring, Woodworking, Jeweling, Alchemism, Scribing, Cooking**
- Crafted gear: choose materials + up to 500+ **Ingredients** (from mobs/quests/chests) → custom stats, durability system, powder slots
- THIS is Skyy's "smithing" — Wynncraft already models create+customize gear

**World & content**
- Hand-built open world (~4000×6000), level-gated regions (Wynn plains → Gavel → Silent Expanse etc.)
- ~260 **Quests** incl. cinematic main-quest arcs; XP + item + unlock rewards
- **Dungeons** (10+, keyed, level-banded) + Corrupted (hard-mode) versions
- **Raids** (4): team challenge gauntlets + boss; source of Aspects & Mastery Tomes
- **World Events**: dynamic wave-defense events spawning in the open world
- **Lootrunning**: endgame roguelite loot circuit w/ boons/curses through procedural caves
- Caves, secret discoveries, Fairy-Soul-like discoveries (xp/lore discoveries)
- **Guilds**: territory war map, guild XP, banks, seasonal wars; parties; Trade Market (Wynn's auction house, 3 slots)
- Mob totems, boss altars (summon bosses w/ materials), corrupted dungeons currency (foreshadowing keys)
- Horses/mounts, emerald currency w/ denominations (E → EB → LE → stacks), scrap/repair? (durability only on crafted)
- Character customization: multiple class slots, tomes, aspects (raid-earned class modifiers)

3. **Smithing** = new headline skill: Wynn-style crafting (materials + ingredients) + SkyBlock-style reforging, one discipline.

# PART 2 — THE MERGE DESIGN (draft)

## 2A. One unified skill list (SkyWynn Skills)
**Gathering:** Farming • Mining • Foraging • Fishing
**Combat:** Combat (weapon XP) + **Class Level** (Wynn-style char level driving ability points)
**Artisan:** **Smithing** (weapons/armor craft + reforge) • Enchanting • Alchemy • Cooking
**Meta:** Taming (pets) • Carpentry (furniture/quickcraft) • Exploration (discoveries/quests)

- Every skill: SkyBlock-style passive XP + level rewards (stats/coins/perks)
- Class Level is Wynn's character level → Ability Points → class ability tree
- Skills gate gear & zones SOFTLY (e.g., T4 pick needs Mining 16; zone mobs shred you without gear that needs your skills)
- HOTM generalized: each gathering skill gets a mini token-tree at higher levels (Mining first)

## 2B. Progression loop (the fusion pitch)
1. Spawn in **Hub Town** (Wynn-style world) → tutorial quest → get **Private Island** (instanced)
2. Quest through level-gated open-world zones (Wynn) while skills grow (SkyBlock)
3. Collections unlock recipes → Smithing crafts your gear (ingredients from world content)
4. Minions on your island automate materials you've personally reached in collections
5. Coins (mob/quest/NPC/bazaar) can BUY most recipe unlocks until midgame wall
6. Midgame: slayers, dungeons, first raid, accessory hunt, ability-tree archetypes come online
7. Endgame: raids, lootruns, world events, guild territory, collection-locked divine crafts

# PART 4 — HYTALE CHAPTER 1 ROADMAP INTEL (researched 2026-09-21)
*Source: official "First Look: Chapter 1 and More" (hytale.com, Jul 16 2026) + Update 7 Part 1 pre-release patch notes (Sep 3). Everything below is Hypixel's WIP and may change.*

## 4A. The Rune Ability System (the thing Skyy flagged)
- **Ability runes** grant active combat abilities; **modifier runes** change how they behave (e.g., ground slam + lightning; fireball that splits into multiple projectiles or applies shock).
- Abilities sit on **two new dedicated inputs, E and R**, alongside the weapon's signature ability.
- **Elemental reactions are engine-native**: wet target + shock = special Water/Lightning reaction; fireball into a friend's tornado = flaming tornado; rain soaks enemies; ice freezes water blocks; fireball + poison barrel = toxic cloud. Co-op combos are an explicit design goal.
- Chapter 1 starts with **~6 ability runes + ~6 modifier runes**. Update 7 Part 1 (pre-release, Sep 3) already ships five ability runes: **Enrage, Fireball, Imbue Poison, Ground Slam, Wind Strike** (no modifier runes yet).
- **Runeforging** (find/craft/expand your rune collection as part of the adventure loop) is planned but **TBD, after Chapter 1**.
- Design intent (their words): RPG depth without funneling players into "a rigid, predefined class or archetype."
- **Status in OUR files (checked Sep 21):** NOT in the current release server jar or Assets.zip (only old decorative rune textures). Skyy's pre-release install is stale (Aug 25). It arrives with the Update 7 waves / Chapter 1.

### What this means for SkyWynn (the big rethink)
1. **Build classes ON TOP of runes, not beside them.** Our Warrior/Archer/Mage should be implemented as *curated rune access*: your class + ability tree decide WHICH ability runes you can equip and WHICH modifier runes unlock. Nodes in the tree = modifier-rune unlocks + passives. This replaces the Spellbook/UnifiedMagicTheory mod route entirely — the engine gives us casting, targeting, VFX, netcode, and elemental reactions for free.
2. **Ability keys decision validated** — the engine is standardizing on E/R ability inputs; that's exactly the input scheme we chose. Zero custom input work.
3. **Elements: adopt Hytale's, not Wynn's.** Engine reactions (water/lightning/fire/poison/wind/ice so far) become our element matrix. Wynn's 5-element gear math gets mapped onto whatever element set Hytale ships, so our gear buffs abilities the engine already knows how to combo.
4. **Runeforging ↔ Smithing collision (design around it now):** Hypixel plans rune find/craft progression later. Fold rune-crafting INTO our Smithing skill + collections (rune recipes gated by collections, like everything else) so when official Runeforging lands we wrap it instead of fighting it. Keep our rune-economy data separate from theirs so an official system doesn't corrupt ours.
5. **Anti-class philosophy note:** Hypixel explicitly avoids rigid classes. We're ADDING classes on top of their classless system — fine for a server, but expect zero engine help for class restrictions; enforcement is ours (equip filters on runes/gear).
